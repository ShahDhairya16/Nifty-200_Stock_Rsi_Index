======================================================================
       NIFTY 200 RSI Dashboard - Complete Windows Run Guide
======================================================================

The backend is a command-line data pipeline. It loads NSE data, calculates
RSI values, and stores everything in local JSON/CSV files under data/.

Run every command from the project root:

  cd D:\Nifty-200_Stock_RSI_Index


1. Install Dependencies
------------------------

  pip install -r requirements.txt


2. Load the NIFTY 200 Universe
------------------------------
Fetches the current NIFTY 200 stocks and stores them in data/stocks.json:

  python main.py --sync-universe


3. Load Historical Prices and RSI Data
--------------------------------------
Backfills historical prices, recovers missing records, calculates RSI values,
and generates the Excel report:

  python main.py --backfill-historical
  python main.py --recover-missing
  python main.py --generate-excel
 
To generate the Excel report through a specific date, use `--end-date`:

  python main.py --generate-excel --end-date 2026-09-07

The generated workbook is saved in the output/ folder.


4. Start the Dashboard
----------------------
Keep the previous commands complete, then open a second PowerShell window.
From the project root, run:

  cd D:\Nifty-200_Stock_RSI_Index
  streamlit run frontend/streamlit_app.py

Open the displayed local URL, normally:

  http://localhost:8501


5. Dashboard Refresh
--------------------
Use the sun/moon icon in the sidebar to switch between light and dark themes.
Use 'Refresh dashboard data' to clear cached reads and reload local files.
This button does not start NSE ingestion.


Optional Backend Check
----------------------

  python -m compileall app frontend main.py
